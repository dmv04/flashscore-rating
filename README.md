# Flashscore rating

Веб-приложение: парсит матчи с flashscore.com и считает рейтинг команд по балансу
забитых/пропущенных через систему линейных уравнений (СЛУ), плюс прогнозы на ближайший тур.

Сезон 2026/2027. Лиги: Англия, Испания, Италия, Германия, Франция, Португалия, Нидерланды,
Бельгия, Турция, Шотландия, Россия (РПЛ). Еврокубки: ЛЧ, ЛЕ, ЛК — для мирового рейтинга.
Список турниров — `app/tournaments.py`.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

Открыть http://localhost:8000. При первом запросе турниры скачиваются с flashscore
и кэшируются в `data/matches.db`; кнопка «Обновить с flashscore» перекачивает текущий сезон.

## Модель

Для команды i по её матчам m против соперников j:

- `δ_im = (З_m + П_m) / (ΣЗ_i + ΣП_i)` — вес матча
- `Δ_i = (ΣЗ_i − ΣП_i) / (ΣЗ_i + ΣП_i)` — относительный баланс
- `Rt_i = Σ δ_im · Rt_j + 1000 · Δ_i`
- `(1/n) · Σ Rt_i = 2200`

**Мировой рейтинг (без России)** = национальный рейтинг + поправка силы лиги. Поправки — решение
тех же уравнений `Rt_i − Rt_j = 1000·Δ_m` (вес З+П) по межлиговым матчам еврокубков текущего
и прошлого сезона; неизвестные только поправки лиг, средний мировой рейтинг 2200.
Прошлый сезон берётся потому, что в начале сезона межлиговых матчей мало.

**Прогноз**: `З(ожид.) = (з+п) × (1000 + (Rt_i − Rt_j)) / 2000`, з+п — среднее число голов
в матчах обеих команд; П1/Х/П2 и вероятный счёт — по Пуассону. Ближайший тур — наименьший
номер тура, где запланировано не меньше четверти матчей тура (перенесённые игры не сбивают).

## API

- `GET /api/meta`
- `GET /api/rating?scope=world|epl|laliga|...|rpl&last_n=8`
- `GET /api/predictions?last_n=8`
- `POST /api/refresh[?tournament=epl]`

## Страница для шаринга

`python -m share.build out.html` — интерфейс со встроенным снимком данных, работает без сервера
(`--fragment` — без `<head>`, для публикации в Claude).

`.github/workflows/pages.yml` каждый день (и после пуша в main) скачивает свежие матчи,
собирает эту страницу и публикует на GitHub Pages: https://dmv04.github.io/slu-rating/
