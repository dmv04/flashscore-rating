Прогноз матча
З(ожид.) = (з+п) × (1000 + (Rti − Rtj)) / 2000; по умолчанию з+п — среднее по лиге.
Как считается рейтинг

Для команды i по её матчам m против соперников j:

δim = (Зm+Пm) / (ΣЗi+ΣПi) — вес матча, Δi = (ΣЗi−ΣПi) / (ΣЗi+ΣПi) — относительный баланс.

Rti = Σ δim·Rtj + 1000·Δi,   (1/n)·ΣRti = 2200

Система из n+1 уравнений решается совместно (метод наименьших квадратов; для совместной системы это точное решение).
