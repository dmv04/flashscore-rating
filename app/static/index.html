Рейтинг команд по балансу голов

Рейтинг — решение системы линейных уравнений по забитым и пропущенным с учётом силы соперников. Средний рейтинг турнира — 2200.
Сила лиги — поправка к национальному рейтингу по матчам еврокубков (текущий и прошлый сезон); в скобках — число межлиговых матчей.
Как считается

Для команды i по её матчам против соперников j: вес матча δ = (З+П)ₘ / (ΣЗ+ΣП), относительный баланс Δᵢ = (ΣЗ−ΣП)/(ΣЗ+ΣП). Уравнения: Rtᵢ = Σ δ·Rtⱼ + 1000·Δᵢ для каждой команды и (1/n)·ΣRt = 2200.

Мировой рейтинг (без России): национальный рейтинг плюс поправка силы лиги. Поправки находятся из тех же уравнений Rtᵢ − Rtⱼ = 1000·Δ по межлиговым матчам Лиги чемпионов, Лиги Европы и Лиги конференций текущего и прошлого сезона. Среднее по всем командам — 2200.

Прогноз: ожидаемые голы З = (з+п) × (1000 + (Rtᵢ − Rtⱼ)) / 2000, где з+п — среднее число голов в матчах обеих команд. Вероятности исходов и самый вероятный счёт — по распределению Пуассона с этими ожиданиями.
